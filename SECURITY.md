# Security

If you find a security problem in this project, please report it privately. Don't open a public issue or pull request
for it.

Use GitHub's private reporting: go to the **Security** tab of this repository and choose **Report a vulnerability**.
Include what you found, how to reproduce it, and which part (database, website, tablet app, Bridge or Helper) it affects.

I'll read reports as soon as I can and will tell you when it's fixed. Please give me a reasonable chance to fix it before
you share the details anywhere.

Please don't:

- test against anyone else's deployment or data
- send real customer messages while testing the Helper
- commit keys, tokens or personal data to this repository. If you spot any in the tree, report it the same way.
